# Download Artemisia

## All operating systems

1. Download the latest the released archive for your operating system: <https://codeberg.org/korpling/artemisia/releases>
2. Extract the contents of the archive file to a location of your choice. The archive contains an executable file.
3. Double click on the executable file to run it.

## Only on macOS 

The application is not signed and thus you have to do some additional steps on macOS:

1. Move the `artemisia` executable file to the `Applications` folder (do not skip this step!) 
![](../images/macos-move-to-applications.png)
2. Run `artemisia` by double clicking on it
3. A dialog will appear that asks you to put it into the trash, do not click on that button but the other one.
![](../images/macos-do-not-trash.png)
4. Go to the system settings on "Data protection and security" and unblock the app
![](../images/macos-unlock.png)
5. Confirm unlocking the app in the next dialog

After these steps you should be able to execute the app directly from the `Applications` folder.
